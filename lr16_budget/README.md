Management reserve. Двома-трьома реченнями скажіть, чим цей резерв відрізняється

baseline. Назвіть один приклад події, яка в нього потрапила б, і одну, яка не
потрапила б, бо для неї є contingency.

причина не швидкість, а недооцінена ємність.
